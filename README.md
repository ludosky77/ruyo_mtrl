# Ruyo Manga Translation & Detection Server (Fastboot Cache)

This public repository hosts pre-packaged AI model weights and runtime caches for the **Ruyo Reader** Google Colab T4 Cloud Pipeline.

### Models Included:
- **Comic-Text-Detector (CTD):** Native 1536x1536 high-resolution speech bubble & dialogue detection.
- **LaMa-MPE:** Large Mask Inpainting with Fast Fourier Convolutions.
- **MangaOCR & 48px CTC:** Scanlation-standard Japanese/CJK optical character recognition.
- **Cloudflared:** AMD64 tunnel binary.
